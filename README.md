# Shangshang Yang's Academic Homepage

Personal academic homepage of [Shangshang Yang](https://devilyangs.github.io/), Associate Professor at Anhui University.

Built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

- Homepage content: `_pages/about.md`
- News: `_news/`
- Publications: `_bibliography/papers.bib`
- Paper detail pages: `_pages/papers/`
- Site config: `_config.yml`, `_data/`

Builds automatically via GitHub Actions (`.github/workflows/deploy.yml`) and deploys to GitHub Pages.
